What are the 5 steps of the V8 JavaScript engine pipeline?	Source code → Tokenize → AST (Abstract Syntax Tree) → Ignition (bytecode interpreter) → TurboFan (optimized machine code). TurboFan deoptimizes back to Ignition if type assumptions are wrong.	javascript
What is the execution order: console.log('A'); setTimeout(() => console.log('B'), 0); Promise.resolve().then(() => console.log('C'));	A, C, B. Synchronous code first, then microtask queue (Promise.then), then macrotask queue (setTimeout). Microtasks always run before macrotasks.	javascript::event-loop
Why does `for (var i = 0; i < 3; i++) { setTimeout(() => console.log(i), 0); }` print 3, 3, 3?	`var` is function-scoped, not block-scoped. All callbacks share the same `i`. By the time they run, the loop is done and `i` is 3. Fix: use `let` (block-scoped) or IIFE.	javascript::closures
Do closures capture values or references?	References. A closure captures a reference to the variable, not a snapshot of its value. If the variable changes, the closure sees the new value.	javascript::closures
What are the 4 rules of `this` binding in JavaScript (in priority order)?	1. `new` binding (constructor) 2. Explicit binding (call/apply/bind) 3. Implicit binding (object.method()) 4. Default binding (global/undefined in strict). Arrow functions have NO own `this` — they use the lexical `this` from the enclosing SCOPE (not enclosing object).	javascript::this-binding
What does `this` refer to in an arrow function?	The `this` from the enclosing LEXICAL SCOPE (where the arrow function is defined), NOT the enclosing object. Arrow functions do not have their own `this` binding.	javascript::this-binding
What is the output of `const obj = { name: 'A', greet: () => console.log(this.name) }; obj.greet();`	undefined. Arrow function `this` is the enclosing lexical scope (module/global), NOT `obj`. To fix: use a regular function `greet() { ... }`.	javascript::this-binding
What happens when you use the spread operator on a nested object? `const a = {x: {y: 1}}; const b = {...a}; b.x.y = 2;`	`a.x.y` is also 2. Spread creates a SHALLOW copy — top-level properties are copied, but nested objects are still shared references.	javascript::shallow-copy
What is the correct status name for a fulfilled Promise — 'resolved' or 'fulfilled'?	'fulfilled'. The three states are: pending, fulfilled, rejected. 'Resolved' is informal and technically means the Promise's fate is determined (could be fulfilled OR rejected).	javascript::async
Does `fetch()` throw an error on HTTP 404 or 500 responses?	NO. `fetch()` only rejects on network failures. HTTP 4xx/5xx responses resolve normally. You must check `response.ok` or `response.status` manually.	javascript::async
What are the 4 Promise combinators and when to use each?	1. `Promise.all` — all must succeed, fails on first rejection. 2. `Promise.allSettled` — wait for all, never rejects. 3. `Promise.race` — first to settle wins. 4. `Promise.any` — first to FULFILL wins, ignores rejections.	javascript::async
What is the useEffect cleanup execution order on re-render?	On re-render: 1) Cleanup of PREVIOUS effect runs first. 2) New effect runs. On unmount: cleanup runs. Cleanup does NOT run on initial mount. This is the #1 useEffect mistake.	react::useEffect
Why does calling `setCount(count + 1)` three times only increment by 1?	State updates are batched in React 18+. All three calls read the same stale `count` value from the current render. Fix: use functional update `setCount(c => c + 1)` — each call gets the latest pending value.	react::useState
When should you use `useRef` instead of `useState`?	When you need a mutable value that does NOT trigger a re-render. Examples: DOM references, previous value tracking, render counters, interval IDs. useRef persists across renders but changes are invisible to React.	react::useRef
What does React.memo do, and what's the most common mistake with it?	React.memo skips re-render if props haven't changed (shallow comparison). Common mistake: passing an unstable prop (new object/array/function created each render) — memo sees a new reference and re-renders anyway. Fix: useMemo/useCallback the prop.	react::performance
What is React's reconciliation algorithm for lists, and why do keys matter?	React uses keys to match old and new elements. Same key = same instance (update in place). Different key = destroy old, create new. Using array index as key breaks this when items are reordered/inserted/deleted.	react::reconciliation
What is layout thrashing and how do you avoid it?	Reading a layout property (offsetHeight) then writing (style.height) then reading again forces the browser to recalculate layout synchronously each time. Fix: batch all reads together, then all writes together.	react::performance
What is `remoteEntry.js` in Module Federation?	It's a MANIFEST file (not the actual module code). It lists what modules are available, their versions, and where to fetch them. The actual code is loaded on-demand when a module is requested.	frontend::module-federation
What is the database scaling progression (don't jump to sharding)?	1. Add indexes → 2. Read replicas → 3. Caching layer (Redis) → 4. Vertical scaling (bigger machine) → 5. Horizontal sharding. Exhaust each step before moving to the next.	system-design::databases
When would you choose Cassandra over PostgreSQL?	Cassandra: write-heavy workloads, massive horizontal scale, partition-tolerant, eventual consistency is OK, time-series data. PostgreSQL: need strong consistency, complex JOINs, relationships, ACID transactions, moderate scale.	system-design::databases
What is polyglot persistence?	Using different databases for different access patterns within the same system. Example: PostgreSQL for user profiles (relational), Cassandra for tweets (write-heavy), Redis for cache (fast reads), Elasticsearch for search.	system-design::databases
What is a hot partition in Cassandra and how do you fix it?	When one partition key receives disproportionate traffic (e.g., a celebrity's tweets). Fix: time bucketing — append a time bucket (e.g., day) to the partition key so data spreads across partitions: `user_id:2026-05-24`.	system-design::databases
What is the outbox pattern and when do you use it?	When you need to update a database AND send a message to Kafka atomically. Write the event to an "outbox" table in the same DB transaction. A separate process reads the outbox and publishes to Kafka. Guarantees no lost events.	system-design::patterns
What is a circuit breaker and what are its 3 states?	Prevents cascading failures when a downstream service is down. States: CLOSED (normal, requests pass through) → OPEN (service down, fail fast without calling) → HALF-OPEN (test with limited requests, if OK go back to CLOSED).	system-design::patterns
Why use cursor-based pagination instead of OFFSET?	OFFSET is O(n) — the database scans and discards rows. For real-time feeds where data changes (new tweets inserted), OFFSET causes duplicates/missed items. Cursor pagination uses a stable pointer (e.g., tweet_id) — consistent and O(1) seek.	system-design::patterns
What is fan-out on write vs fan-out on read, and when to use hybrid?	Fan-out on WRITE (push): when a user posts, push to all followers' feeds immediately. Fast reads, slow writes. Fan-out on READ (pull): when reading, fetch from all followed users. Slow reads, fast writes. Hybrid: push for normal users, pull for celebrities (>100K followers), merge at read time.	system-design::patterns
What is cache warming and when do you need it?	Pre-populating the cache with hot data before routing traffic to a new server. Needed after: cache restart, new deployment, scaling up. Without it: thundering herd — all requests miss cache and hit DB simultaneously.	system-design::patterns
What is the difference between 301 and 302 redirects for a URL shortener?	301 = permanent redirect (browser caches it, won't hit your server again). 302 = temporary redirect (browser always hits your server first). Use 302 for URL shorteners: allows analytics tracking and lets you change the destination later.	system-design::url-shortener
What is Base62 encoding and why use it for short URLs?	62 characters (a-z, A-Z, 0-9). With 7 characters: 62^7 = 3.5 trillion unique URLs. URL-safe (no special characters). More compact than Base64 (no +, /, =).	system-design::url-shortener
What is the difference between rate limiting and caching for handling high traffic?	Rate limiting = abuse protection (block bad actors, prevent DDoS). Caching = load handling (serve legitimate traffic faster). NEVER rate-limit legitimate viral traffic — use caching layers instead (local cache → Redis → replicas → CDN).	system-design::patterns
What are P99, P95, and P50 latency?	P50 = median (50% of requests are faster). P95 = 95% of requests are faster (5% are slower). P99 = 99% of requests are faster (only 1% are slower). Use P99 for SLAs — it captures worst-case user experience. Example: "P99 < 200ms".	system-design::nfr
What is the CAP theorem and when does it actually apply?	In a distributed system, you can't have all 3: Consistency, Availability, Partition tolerance. BUT the trade-off only matters DURING a network partition. When the network is healthy, you can have both C and A. Choose CP (banking) or AP (social media) based on what to sacrifice during partitions.	system-design::distributed
What is an inverted index and where is it used?	A data structure that maps each word to the list of documents containing it. Used in search engines (Elasticsearch, Lucene). Instead of scanning every document, you look up the word and instantly get all matching documents.	system-design::search
What is a Snowflake ID?	A 64-bit globally unique, time-sortable ID. Structure: timestamp (41 bits) + machine ID (10 bits) + sequence number (12 bits). Used by Twitter, Discord. Advantage: sortable by creation time, no central coordinator needed.	system-design::ids
What is quorum in distributed systems?	The minimum number of nodes that must agree for a read/write to succeed. Formula: W + R > N (where W=write quorum, R=read quorum, N=total replicas). Ensures at least one node has the latest data. Example: N=3, W=2, R=2.	system-design::distributed
What is the notification aggregation pattern?	Batch similar events instead of sending individual notifications. Example: "John and 5 others liked your tweet" instead of 6 separate notifications. Implemented with a time window + grouping key in the notifications pipeline.	system-design::patterns
RPS formula for capacity estimation?	RPS = DAU × (actions per user per day) / 86,400 seconds. Example: 100M DAU × 7 reads/day / 86,400 = ~8,100 read RPS.	system-design::capacity
Storage estimation formula?	Storage/day = DAU × upload_percentage × average_file_size. Example: 100M DAU × 10% upload × 200KB = 2TB/day.	system-design::capacity
Redis memory estimation formula?	Memory = number_of_entries × avg_entry_size × replication_factor. Example: 100M entries × 500 bytes × 3 replicas = 150GB.	system-design::capacity
What is RAG (Retrieval-Augmented Generation)?	A pattern where an LLM retrieves relevant context from an external knowledge source (vector DB, search index) before generating an answer. Reduces hallucinations, grounds responses in your data, cheaper than fine-tuning, knowledge stays up-to-date without retraining.	ai::rag
When should you use RAG vs fine-tuning vs prompt engineering?	Prompt engineering: first try, cheapest, for behavior/format changes. RAG: when knowledge changes frequently, you need citations, domain-specific data. Fine-tuning: when you need specific style/behavior, knowledge is stable, RAG retrieval quality is insufficient. Escalation ladder: prompt → RAG → fine-tune.	ai::architecture
What are the components of a production AI agent?	Orchestrator + LLM + Tool interface layer + Memory (short-term + long-term) + Policy/guardrails engine + Observability. The LLM is only ~20% of a production agent system. The rest is engineering.	ai::agents
What is the agent loop (ReAct pattern)?	Perceive (receive input) → Reason (LLM thinks about what to do) → Act (call a tool or generate output) → Observe (check the result) → Repeat or Terminate. This loop is the core of autonomous AI agents.	ai::agents
What are the 3 types of memory in AI agents?	1. Short-term: conversation history within a session (context window). 2. Long-term: user preferences/facts across sessions (vector DB or key-value store). 3. Entity memory: extracted entities and relationships (structured data).	ai::agents
What is context engineering (2026 term)?	Designing the full information environment around an LLM — not just the user prompt. Includes: system prompt, retrieved context (RAG), tool results, conversation history, guardrails. It's the evolution of "prompt engineering."	ai::llm
What is the difference between an AI agent and a simple LLM chain?	A chain follows a fixed sequence of steps. An agent decides dynamically what to do next based on observations. Agents can loop, retry, choose tools, and handle errors — chains can't. Agents have autonomy; chains have structure.	ai::agents
What are guardrails in AI systems?	Safety mechanisms that constrain AI behavior: input validation (reject harmful prompts), output filtering (block inappropriate content), tool use policies (limit what tools agents can call), cost controls (token budgets), human-in-the-loop (escalate uncertain decisions).	ai::safety
What is the cost model for LLM API calls?	Cost = (input_tokens + output_tokens) × price_per_token. Strategies to reduce cost: prompt caching, shorter prompts, batching requests, using cheaper models for simple tasks, streaming to reduce perceived latency. Always estimate cost before scaling.	ai::llm
What does a Senior Staff/Principal Engineer do differently in the AI era (2026)?	Orchestrate human + AI teams (not just write code). Set AI governance guardrails. Design AI-native platforms. Evaluate AI build-vs-buy with cost modeling. Measure AI-augmented team output quality. Define where AI can be trusted and where it can't.	career::principal
What is the scope difference between Staff Engineer and Senior Staff/Principal?	Staff: 2-4 teams, technical depth in one domain, leads projects. Senior Staff/Principal: 10-30+ teams (50-150 engineers), org-wide architecture, defines patterns all teams follow, partners with Directors/VPs, authors multi-year technical strategy.	career::principal
What new skill does a Principal Engineer need that a Staff Engineer doesn't?	Business acumen. Staff needs soft skills. Principal needs business skills: understanding revenue/cost, P&L, ROI of technical decisions, framing every proposal in business terms, partnering with product/finance leadership.	career::principal
What is an Architecture Decision Record (ADR)?	A document capturing an important architectural decision: Context (why), Decision (what), Status (proposed/accepted/deprecated), Consequences (trade-offs). Used to create institutional memory and drive cross-team alignment.	career::principal
What are Amazon's most critical Leadership Principles for L7?	Earn Trust (influence across orgs without authority), Ownership (go beyond job scope), Have Backbone; Disagree and Commit (disagree with leadership + commit), Bias for Action (decide with incomplete data). Red flag: only disagreeing DOWN the org chart.	interview::amazon
What is unique about Google L7 system design interviews?	TWO full system design rounds (both weigh heavily). Back-of-envelope calculations mid-design. Scale reasoning in billions. Evolution thinking (10K → 100M → 1B users). Failure modes for every component. "Googleyness": emergent leadership, comfort with ambiguity.	interview::google
What is unique about Meta E7 interviews?	Technical Retrospective round: "Tell me about a project that changed company direction." Cross-functional partnership round. System design needs BOTH HTTP-status-code depth AND strategic-tradeoff breadth in the same session. ~3% of Meta SWEs are E7.	interview::meta
How should a STAR story be structured for L7/E7 interviews?	Situation (2 sentences, set the stakes). Task (what was your specific responsibility). Action (detailed, use "I" not "we", show judgment). Result (quantified: before/after metrics). 2-3 min for initial story, 5-8 min follow-up depth available. Stakes must be org-level, not team-level.	interview::behavioral
What is the performance debugging workflow (systematic, not exploratory)?	1. Measure (don't guess — use Chrome DevTools/Lighthouse/React Profiler). 2. Identify the bottleneck category (network/rendering/JavaScript). 3. Isolate the specific component/function. 4. Fix one thing. 5. Measure again. Never "open DevTools and poke around."	react::performance
What are SLOs, SLIs, and SLAs?	SLI (Service Level Indicator): a metric (e.g., request latency). SLO (Service Level Objective): a target for the SLI (e.g., P99 latency < 200ms). SLA (Service Level Agreement): a contract with consequences if SLO is breached. SLO is internal commitment, SLA is external contract.	system-design::reliability
What is an error budget in SRE?	The allowed amount of unreliability. If SLO is 99.9% uptime, error budget is 0.1% (~43 min/month). When budget is exhausted: freeze feature releases, focus on reliability. When budget is healthy: ship faster, take risks. Balances innovation vs stability.	system-design::reliability
